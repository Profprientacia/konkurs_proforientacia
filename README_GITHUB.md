# Сайт конкурса 2026 — готовый пакет для GitHub Pages

Этот комплект предназначен для публикации статического HTML-сайта через GitHub Pages.

## Файлы

- `index.html` — готовый сайт.
- `emblema-konkursa.png` — эмблема конкурса.
- `favicon.png` — значок сайта.
- `og-image.png` — изображение для предпросмотра ссылки в соцсетях и мессенджерах.
- `.nojekyll` — файл для GitHub Pages.
- `404.html` — простая страница ошибки.
- `FORM_SETUP.md` — информация о форме заявки.

## Публикация

1. Создайте аккаунт на GitHub.
2. Создайте публичный репозиторий, например `konkurs-proforientaciya-2026`.
3. Загрузите в корень репозитория все файлы из этой папки.
4. Откройте `Settings` → `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`.
6. Выберите ветку `main` и папку `/ (root)`.
7. Нажмите `Save`.
8. После публикации GitHub покажет адрес сайта вида:
   `https://ВАШ-ЛОГИН.github.io/konkurs-proforientaciya-2026/`

## Важно

Форма в этой версии не требует сервера: она формирует письмо на `sektor_primpp@mail.ru`. Пользователю нужно приложить конкурсные документы самостоятельно.

Если нужна форма, которая сохраняет заявки в онлайн-таблицу/панель без почтового клиента, смотрите `FORM_SETUP.md`.
