# Форма заявки

## Текущий вариант — без сервера и без оплаты

На сайте форма проверяет обязательные поля и открывает почтовое приложение с подготовленным письмом на:

`sektor_primpp@mail.ru`

Это самый простой вариант для статического сайта GitHub Pages.

## Если нужна полноценная онлайн-форма

Статический HTML сам по себе не имеет базы данных. Для автоматического сохранения заявок понадобится внешний сервис форм или небольшой сервер.

Практичный вариант: Formspree. После регистрации сервис выдаёт URL формы вида:

`https://formspree.io/f/XXXXXXXX`

После получения URL форму можно переключить с `mailto:` на отправку в сервис. До получения собственного endpoint ничего выдумывать или прописывать не нужно.

Для конкурсных материалов всё равно рекомендуется оставить официальный e-mail `sektor_primpp@mail.ru`, поскольку именно он указан в Положении конкурса.
